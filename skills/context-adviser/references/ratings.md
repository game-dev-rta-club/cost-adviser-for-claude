# Rating a proposal

Give every proposal 1–5 stars on each axis below, in its `ratings`
(`ease`, `safety`, `savings`), as numbers. The overall rating shown on the
report is the rounded average of the three. **Leave out a proposal with 2
stars or fewer on any axis**: `cca advise` refuses it. If nothing good is left
for a finding, say so in the reply instead of offering weak proposals.

| Stars | Ease of use (`ease`) | Few side effects (`safety`) | Savings (`savings`) |
|---|---|---|---|
| 5 | Set up once, then it works with no attention | No loss of quality, speed or context expected | Touches 30% or more of cost |
| 4 | Set up once, with an occasional check | A tiny cost the user is unlikely to notice | 20–30% |
| 3 | A small routine at natural points, or a setup that needs some upkeep | A small, visible cost that is easy to undo | 10–20% |
| 2 | The user must remember it often | Noticeable friction or slower work | 5–10% |
| 1 | The user must remember it every time | Risks the quality of the work | Under 5%, or no clear link to the numbers |

Base `savings` on the share of cost the proposal touches in the linked view,
and say that share in the detail. Rate from these definitions, not from a
general impression, so the same proposal gets the same stars each time.
